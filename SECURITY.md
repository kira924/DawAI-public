# Security Policy

## Supported Code

Only the latest commit on the default branch is considered for security fixes.
This project is pre-release software and currently has no supported production
version.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting for this repository. Include the
affected component, reproduction steps, potential impact, and any suggested
mitigation.

Do not disclose suspected vulnerabilities in public issues, discussions, pull
requests, screenshots, or logs. Do not include real credentials, access tokens,
database URLs, pharmacy records, customer data, or patient data in a report.

The maintainer will acknowledge a complete report when practical, investigate it,
and coordinate disclosure after a fix or mitigation is available. No response-time
or bounty commitment is currently offered.

## Scope

Security reports about authentication, authorization, tenant isolation, inventory
integrity, financial integrity, secret exposure, and dependency vulnerabilities
are especially useful. Reports that require destructive testing against systems
or data not owned by the reporter are out of scope.
