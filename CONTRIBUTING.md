# Contributing

DawAI is currently published as a review and demonstration snapshot while its
licensing and external-contribution model are being decided.

Bug reports and security reports are welcome. Please use GitHub issues for
non-sensitive defects and follow `SECURITY.md` for vulnerabilities. External code
contributions are not being accepted yet; opening a pull request does not grant a
license to the project or create an obligation to merge the contribution.

When contributions open, changes will be expected to preserve tenant isolation,
authorization boundaries, exact monetary arithmetic, inventory auditability,
migration safety, and the repository's automated quality gates.
